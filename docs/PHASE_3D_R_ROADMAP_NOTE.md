# Phase 3D-R — Roadmap note

Phase 3D-R is a design/audit gate only. The authoritative contract is
[`STABLE_DAY_IDENTITY_DESIGN.md`](STABLE_DAY_IDENTITY_DESIGN.md).

Decision: approve a narrow stable-day-identity successor. A future `ManualPlanningDraftV5` may give
persisted day buckets opaque stable ids and bind each accommodation boundary to its day entity so
ordinary user-authored edits can preserve the day decision without heuristic matching.

No runtime, UI, dataset, dependency, routing, optimization, scheduling, luggage, booking, geocoding
or transport-evidence change is implemented by Phase 3D-R.

Recommended successor: **Phase 3D-S — Stable Day Identity Runtime**. Phase 3D-S is **NOT STARTED** by
this gate.
